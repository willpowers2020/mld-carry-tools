Terms

2DP 2-Digit Pair — any 2 of the 4 digits in a Pick 4 number, sorted ascending. Each number has C(4,2)=6 pairs. 3DP 3-Digit Triple — any 3 of the 4 digits, sorted ascending. Each number has C(4,3)=4 triples. Narrower PL than 2DP. Carry When a pair/triple from a recent draw appears in a later winner. 2DP uses same-day; 3DP uses a 3-day window. Heat14 How many times a pair appeared in that state's draws over the last 14 days. Heat14=0 means "cold" (unseen). Only Carrier When exactly one pair carried for a state — no dilution. Higher only-carrier rate = stronger signal. PL Prediction List — the set of numbers to play based on a signal. Click any pair to see its full PL.
